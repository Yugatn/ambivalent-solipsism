# Версии «Сюжета Икс»

Роман развивается в нескольких параллельных редакциях.

## V1 — Каноническая
Основная линия. Метафизическая фантастика о Юджине, Мире, Югатне, переходах между жизнями и постепенно раскрывающемся устройстве реальности.

## V2 — Quantum
Та же исходная история, но гипотеза многомировой структуры становится центральной. Важные развилки могут создавать устойчивые линии.

## V3 — Ambiguous
Максимально неоднозначная версия. Сверхъестественные события получают минимум две возможные интерпретации: метафизическую и психологическую/технологическую.

Версии не считаются ошибками друг друга. Это разные траектории одного исходного материала.
