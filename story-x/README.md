# STORY_X — литературное и интерактивное пространство

«Сюжет Икс» теперь развивается в двух связанных слоях: литературном и интерактивном. Основной художественный текст новой версии находится в `novel.md`; интерактивный граф остаётся экспериментальным интерфейсом и архивом нелинейных маршрутов.

## Файлы

- `index.html` — интерфейс и движок.
- `story_x_graph.json` — граф сцен, выборов и состояния.
- `novel.md` — новое литературное ядро романа.
- `README.md` — описание архитектуры.

## Принцип

Статический сайт без backend и внешних зависимостей.

Читатель проходит сцены, делает выборы и получает другую последовательность. Выборы не являются оценкой «правильно/неправильно»: они меняют состояние версии истории.

Состояние хранится в `localStorage` под ключом `story-x-state-v1`.

Кнопка «Начать сначала» сбрасывает текущую ветку.

## Граф

У сцены есть `chapter`, `title`, `text`, `choices`. У выбора есть `label`, `to`, необязательные `effects` и `when`.

## Кино-карта

Кино-карта является отдельным узлом внутри того же графа. В неё можно попасть из нескольких точек. Фильмы используются как карты вопросов о восприятии, памяти, времени и субъекте, а не как готовые объяснения.

## Residual

Граф не должен превращаться в полное объяснение романа. Некоторые события намеренно остаются неопределёнными. Состояние читателя не равно «истине мира».

## Локальный запуск

GitHub Pages работает напрямую. Для локального запуска используйте простой HTTP-сервер из каталога `story-x`, потому что браузер может блокировать `fetch()` JSON при открытии `index.html` как `file://`.

## Литературный принцип

Новая версия строится не как набор независимых миниатюр, а как связный роман с обратными связями. Сначала читатель получает событие, затем его последствия, а позднее может узнать причину. Поздняя глава может изменить смысл ранней.

Основные линии: Юджин и Мира; трансперсональные путешествия; Садху и начало пандемии; Югатн; Вьетнам; поиск единомышленников и финансирования революционного проекта; чёрные деньги как загадка потоков влияния; Ульяновск и мотив перерождения; Революция Юджина; Закон Развития; Амбивалентный Солипсизм.

Развилки редкие. Читатель прежде всего читает полноценные художественные страницы; переходы возникают в смысловых узлах. Не все тайны получают окончательное объяснение.
