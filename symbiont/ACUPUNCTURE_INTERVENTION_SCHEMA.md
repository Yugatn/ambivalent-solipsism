# Acupuncture Intervention Schema

## Required record
- technique
- indication
- body_sites
- needle_count
- needle_type
- stimulation_mode
- session_duration
- practitioner_qualification
- sterile_protocol
- baseline_state
- concurrent_interventions
- subjective_outcomes
- physiological_outcomes
- clinical_outcomes
- adverse_events
- stop_reason
- evidence_status
- uncertainty

## Principle
Different acupuncture techniques are separate interventions unless equivalence has been demonstrated.
