# Holographic Epistemic Gate

## Before using the term holographic
1. Is this optical holography?
2. Is this holographic microscopy?
3. Is this quantum-gravitational holographic principle?
4. Is this a neurotheoretical hypothesis?
5. Is it only an analogy?

## Prohibited inference
Do not infer consciousness, soul, solipsism, reincarnation or psychophysical energy from holographic physics alone.

## Rule
**Holographic terminology must identify a mechanism, mathematical structure or explicit analogy.**
