# Interoception Protocol

## Purpose
Separate bodily signal, awareness, accuracy and interpretation.

## Layers
- Physiological signal: measurable internal bodily event.
- Sensibility: reported tendency to notice bodily sensations.
- Accuracy: correspondence between report and measured state under a defined task.
- Awareness: conscious access to the signal.
- Interpretation: meaning assigned to the signal.

## Protocol
1. Record physiological reference.
2. Record subjective report.
3. Record confidence.
4. Specify task and context.
5. Compare report with measurement when a validated comparison exists.
6. Record discrepancies without assuming error.

## Safety
Interoceptive attention can amplify concern in some contexts. The system must not encourage repeated checking when it increases distress or unsafe behavior.

## AS invariant
**Sensation ≠ Interpretation.**
**Awareness ≠ Accuracy.**
**Interoception ≠ Diagnosis.**
