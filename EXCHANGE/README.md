# EXCHANGE — обменник материалов AS

Эта папка предназначена для временного обмена материалами проекта.

## Структура

- `INBOX/ART/` — изображения, арты, обложки, референсы.
- `INBOX/AUDIO/` — мелодии, музыкальные фрагменты, звуковые материалы.
- `INBOX/VIDEO/` — видео и видеореференсы.
- `INBOX/DOCS/` — дополнительные документы и тексты.

## Как работать

1. Загружай файл в соответствующую папку через GitHub.
2. По возможности давай понятное имя файла.
3. В сообщении в чате указывай, что именно нужно сделать с материалом.
4. После обработки файл можно переместить в соответствующий постоянный раздел проекта или удалить из INBOX.

## Важно

GitHub подходит для файлов небольшого и среднего размера. Для очень больших видео/аудио GitHub имеет ограничения, поэтому такие материалы при необходимости лучше хранить через Git LFS или отдельное файловое хранилище.

Эта папка является рабочим обменником, а не окончательным архивом всех медиа проекта.
