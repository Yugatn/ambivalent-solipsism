# PROF-MAP — Integration Layer

PROF-MAP должен развиваться как центральная профессиональная навигация, а не как замена уже созданным инструментам.

## 1. Cattell / 16PF

Cattell остаётся самостоятельным assessment-модулем.

Его результаты могут отображаться рядом с PROF-MAP, но не смешиваются автоматически с Match.

Причина: разные инструменты измеряют разные конструкты и имеют разный психометрический статус.

## 2. Колесо баланса

Wheel of Balance хорошо интегрируется с развитием:

```
PROF-MAP
  |
  v
Professional direction
  |
  v
Skill Gap
  |
  v
30/60/90 plan
  |
  v
Wheel of Balance
```

Колесо может использоваться для оценки жизненного контекста и отслеживания изменений после плана развития.

## 3. Профессиональный профиль

После PROF-MAP пользователь может сформировать отдельный Professional Profile:

- профессиональные интересы и предпочтения;
- цифровой профиль;
- AI-профиль;
- навыки;
- подтверждённые результаты;
- зоны развития;
- портфолио.

Это не должно автоматически становиться резюме с психологическими оценками.

## 4. Будущие модули

Архитектура допускает:

- каталог профессий;
- ESCO skills;
- учебные маршруты;
- практические задания;
- портфолио;
- вакансии;
- анонимизированное исследовательское хранилище;
- AI-помощника интерпретации.

## 5. Главный принцип

Один пользовательский интерфейс может объединять инструменты, но каждый инструмент сохраняет собственную методологию.

```
PROF-MAP
├── Professional Profile
├── AI Profile
├── Skill Map
├── Cattell
├── Wheel of Balance
└── Future assessment modules
```

Интеграция означает обмен структурированными результатами, а не смешивание психометрических шкал.
