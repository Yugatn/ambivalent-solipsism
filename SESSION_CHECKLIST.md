# Рабочий чек-лист сеанса

Этот чек-лист является краткой операционной формой GITHUB_WORK_PROTOCOL.md.

## Вход

- Проверен резервный контекст.
- Проверена карта репозиториев.
- Определён текущий слой.
- Определён канонический источник.
- Прочитан дизайн, если меняется интерфейс.
- Найдены связанные материалы.
- Проверены незавершённые задачи.

## Во время работы

- Используется актуальный SHA.
- Новая информация получает статус.
- Устанавливаются смысловые связи.
- Проверяются входящие зависимости.
- Не копируется канон без необходимости.
- Критика и неизвестность сохраняются.
- Эксперимент не превращается автоматически в утверждение.

## Перед выходом

- Проверены изменённые файлы.
- Проверены ссылки.
- Проверена навигация.
- Проверен дизайн.
- Проверены зависимые репозитории.
- Обновлена карта связей при необходимости.
- Зафиксированы commit SHA.
- Подготовлена резервная запись.
- Открытые вопросы записаны.
