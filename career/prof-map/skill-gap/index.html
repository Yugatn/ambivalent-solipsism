PROF-MAP / 0.4 / SKILL GAP

Что нужно развить?

Skill Gap переводит карьерную гипотезу в понятный план. Здесь нет оценки «хороший» или «плохой». Есть разница между текущим профилем и требованиями конкретной роли.

Как читать результат

УЖЕ ЕСТЬ — навык отмечен в вашем профиле.

ЧАСТИЧНО — навык связан с вашим профилем, но пока нет достаточного подтверждения.

ТРЕБУЕТ ПРОВЕРКИ — навык важен для роли, но в профиле его пока нет.

Отсутствие навыка не означает отсутствие способности. Skill Gap показывает только текущую дистанцию до выбранной роли.
