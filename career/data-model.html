Модель данных PROF-MAP

Основные сущности

  • Person — пользовательский профиль;
  • Ability — функциональная способность;
  • Skill — конкретное умение;
  • Context — условия работы;
  • Interest — предпочтение по типу задач;
  • Occupation — профессия или роль;
  • MarketSignal — внешняя информация о рынке;
  • Evidence — основание, подтверждающее утверждение;
  • Gap — разрыв между текущим профилем и выбранной целью;
  • Experiment — действие для проверки карьерной гипотезы.

Связи

Person затем Ability затем Context затем Occupation и отдельно Person затем Skill затем Evidence. Рыночные данные не должны переписывать профиль человека; они определяют, где и насколько востребовано определённое сочетание навыков.

Версионность

Профиль должен иметь историю изменений. Человек может получить новые навыки, изменить интересы, сменить контекст или пересмотреть профессиональную гипотезу.

Принцип данных

Минимизация данных, прозрачность основания результата, возможность исправления информации и экспорт собственного профиля. Исследовательские данные должны обезличиваться.
