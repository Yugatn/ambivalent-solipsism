# Content Passport UX Specification v0.1

## Цель
Сделать измерения визуально отличимыми от рейтинга.

1. Не использовать progress bars для долей контента.
2. Не использовать stars, scores или good/bad/better/worse badges.
3. Рядом с числом показывать единицу и смысл: `37 событий`, `8.9% времени`, `5.8% планов`.
4. Статус observed/validated/preliminary/unknown является частью основного блока.
5. По клику раскрываются формула, исходные интервалы, provenance, uncertainty и validation status.
6. Временная карта предпочтительнее процентной полосы.
7. Сравнение допускается только по структурным измерениям; UI не формирует winner/better/worse.

## Card layout
Identification -> Visual -> Creators -> Plot/Context -> Technical -> Content Map -> Uncertainty/Provenance -> Method/Version.

Цвет не должен быть единственным носителем статуса.
