# Ontology Governance v0.1

## Roles

### Core Ontology Council
Проектная модель: 5–7 специалистов по media studies, psychology, ML/data и methodology. Responsibilities: core changes, methodological review, conflict-of-interest declarations, publication of decisions and rationale.

### Community Review
Public RFC, минимум 30 дней обсуждения, pilot >=100 fragments для substantive additions where feasible, опубликованный ответ на основные objections.

### Forks
Alternative ontologies имеют unique ontology_id, version, mapping tables и documented incompatibilities.

## Change process
proposal -> RFC -> public review -> pilot -> validation -> decision -> version bump -> changelog -> optional recalculation.

## Cultural variation
Universal observable features и culture-specific interpretation должны быть разделены; культурные предпосылки — явные поля.

## Conflict of interest
Каждое решение фиксирует participants, declared conflicts, abstentions, rationale и evidence considered.
