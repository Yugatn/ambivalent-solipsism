# Колесо онтологии контента

## Radial-визуализация социальных программ в медиа

**Статус:** draft  
**Версия:** 0.1.0

### Принцип

Колесо — визуализация структуры контента, а не его ценности. Оно не является рейтингом, рекомендацией или оценкой качества.

> **Колесо показывает форму, а не ценность.**

### Формальная модель

Онтология:
$$\mathcal{O}=\{C_1,\ldots,C_{10}\},\qquad \Omega=\bigcup_k C_k.$$

Для программы \(\omega\) строится вектор:
$$\mathbf v_\omega=\langle P_\omega,T_\omega,C_\omega,\rho_\omega,R_\omega,A_\omega,U_\omega\rangle.$$

Для выбранной нормированной метрики \(m_\omega\in[0,1]\):
$$r_\omega=r_0+\Delta r\,m_\omega.$$

Профиль:
$$\mathcal W_m=\{(r_\omega\cos\theta_\omega,r_\omega\sin\theta_\omega):\omega\in\Omega\}.$$

Угловая раскладка фиксирована онтологией: начало — 12 часов, направление — по часовой стрелке.

### Семейство колёс

- **presence** — присутствие программы;
- **time** — доля экранного времени;
- **density** — плотность событий;
- **context** — контекстные признаки;
- **uncertainty** — неопределённость;
- **network** — структурные связи.

Эти представления не следует смешивать в один показатель.

### Уровни репрезентации

- `obs` — наблюдаемый факт;
- `rep` — представлен как значимый;
- `rwd` — нарративно вознаграждён;
- `adv` — присутствуют явные признаки продвижения;
- `rfc` — повторяющийся паттерн подкрепления;
- `eff` — эффект на субъекта, только по отдельному response study.

**Важно:** `adv` не вычисляется автоматически из частоты. Любое утверждение об advocacy требует отдельного codebook, доказательств и неопределённости.

### Ограничения

1. Нельзя менять порядок программ между произведениями.
2. Нельзя скрывать программы из-за низкого значения.
3. Цвет обозначает класс, а не позитивность/негативность.
4. `obs`, `rep`, `adv` не должны сливаться в один визуальный показатель.
5. Confidence и uncertainty публикуются рядом с измерением.
6. «Неизвестно» не заменяется нулём без явного правила данных.
7. Форма колеса не доказывает причинность, влияние на аудиторию или вред.

### Метрики формы

$$G=\frac{\sum_{i,j}|m_i-m_j|}{2n^2\bar m}$$

$$H=-\sum_i p_i\log p_i,\qquad p_i=\frac{m_i}{\sum_jm_j}.$$

$$H_{norm}=\frac H{\log n}.$$

Для сравнения профилей:
$$d(A,B)=\sqrt{\sum_\omega(m^A_\omega-m^B_\omega)^2}.$$

Эти показатели описывают форму и расстояние между профилями; они не являются оценками качества произведения.
