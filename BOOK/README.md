# КНИГА AS — рабочая редакция

> **СТАТУС: В РАЗРАБОТКЕ**

Этот раздел предназначен для постепенного переноса авторской книги «Амбивалентный солипсизм» в GitHub.

## Принцип работы

Книга не заменяется кратким конспектом. Материал переносится блоками, чтобы его можно было:

- расширять;
- уточнять;
- исправлять;
- связывать с философией AS, исследованиями и техническими системами;
- отделять авторскую метафизику от научных утверждений.

### Маркировка

- **[AS]** — авторская философская концепция.
- **[SCIENCE]** — утверждение, которое требует научного источника или опирается на установленное знание.
- **[MODEL]** — формальная или объяснительная модель.
- **[HYPOTHESIS]** — гипотеза, не установленная как факт.
- **[UNKNOWN]** — вопрос, на который в рамках проекта нет достаточного знания.

Каждый новый блок получает пометку:

> **СТАДИЯ РАЗРАБОТКИ — содержание может быть дополнено или уточнено.**

Это не означает, что уже сформулированная авторская позиция является «черновиком». Пометка означает открытость блока для дальнейшего развития.

## Важно

GitHub является рабочим архивом проекта. Тексты могут развиваться вместе с исследованием. Научные утверждения должны проходить отдельную проверку и не должны автоматически превращать философскую гипотезу в научный факт.
