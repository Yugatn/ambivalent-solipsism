# SOURCE BOOK

Загрузите сюда исходный файл книги для внутренней сверки проекта. Папка намеренно начинается с точки и предназначена для авторского исходника.

Важно: GitHub не делает такую папку приватной. Если репозиторий публичный, загруженный сюда файл также будет доступен по прямой ссылке. Для действительно приватной книги нужен приватный репозиторий.
