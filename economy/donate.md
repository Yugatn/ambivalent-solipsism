# Поддержать развитие AS

> **Помощь революционеру мира**

Амбивалентный Солипсизм — авторский проект, который объединяет философию, искусство, психологию, искусственный интеллект и экспериментальные цифровые системы.

Проект развивается благодаря времени, интеллектуальному труду, техническим ресурсам и добровольной поддержке людей.

## Поддержать автора

**💠 Поддержать автора**

Добровольная помощь может использоваться для:

- разработки проекта AS;
- создания программ и приложений;
- исследований;
- искусства;
- музыки и видео;
- публикации материалов;
- технической инфраструктуры;
- социальных инициатив.

Поддержка не является покупкой доли проекта или финансовой инвестицией.

## Принцип добровольности

Поддержка должна оставаться добровольной.

Размер вклада не определяет ценность человека.

Вклад является ресурсом, который может помогать проекту продолжать развитие.

> **Один большой вклад может помочь сегодня.  
> Миллион маленьких вкладов может создать инфраструктуру будущего.**

Поэтому AS исследует модель добровольного распределённого участия — **Δ⁺**.

## Прозрачность

По мере развития проекта планируется публиковать информацию о направлениях использования средств.

Экономика проекта должна оставаться наблюдаемой настолько, насколько это возможно без нарушения приватности участников.
