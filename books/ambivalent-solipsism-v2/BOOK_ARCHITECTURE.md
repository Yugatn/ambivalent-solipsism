# Архитектура новой версии книги

Новая структура строится **параллельно со старой**. Файл `books/ambivalent-solipsism.html` не удаляется и не переписывается в рамках миграции.

## Принцип

Старая книга является исходным корпусом. Новая книга формируется копированием существующего текста в отдельные файлы глав с последующим расширением.

Каждая глава получает устойчивый идентификатор. В дальнейшем внутри главы смысловые единицы могут быть дополнительно разделены на отдельные файлы без потери исходного текста.

## Слои

1. **Legacy** — существующая монолитная книга, сохраняемая без удаления.
2. **Chapter Sources** — отдельные исходники глав новой книги.
3. **Graph** — связи между понятиями, главами и смысловыми единицами.
4. **Manifest** — порядок сборки книги.
5. **Generated Reader** — будущая HTML-версия, собираемая из исходников.

## Правила миграции

- старый текст не удаляется;
- существующие формулировки не сокращаются;
- новая версия может содержать дополнительный материал;
- нумерация старой версии не исправляется автоматически;
- структурный аудит выполняется отдельно;
- «Сюжет Икс» не включается в корпус книги;
- публичный текст не использует стрелочные символы;
- статус утверждений сохраняется;
- неизвестное и критика являются частью структуры;
- связи между темами должны быть явными.

## Следующий этап

После переноса глав каждая глава постепенно разбивается на атомарные смысловые единицы. Каждая единица получает `id`, статус, определение, границы значения, связи, критику и открытые вопросы.
