# Symbiont Bridge v0.1

Этот протокол связывает философские принципы AS с операционными состояниями Symbiont Node.

| Принцип AS | Операционное состояние |
|---|---|
| R неизвестно | REPORT_INCOMPLETE |
| Недостаточно evidence | NOT_TESTED |
| Конфликт свидетельств | CONFLICTED |
| Необратимый риск | BLOCKED или NEEDS_REVIEW |
| Допустимое проверенное действие | ALLOW |

Мост не превращает философскую формулу в доказательство. Он задаёт способ сохранять неопределённость при исполнении.
