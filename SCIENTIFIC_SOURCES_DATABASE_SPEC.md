# База научных источников

Каноническая база научных источников экосистемы будет вынесена в отдельный репозиторий scientific-sources.

## Назначение

База хранит проверяемые библиографические записи, устойчивые идентификаторы, ссылки на первоисточники, тип источника, дату проверки, связанные утверждения и ограничения.

## Принцип

GitHub является рабочей точкой доступа к базе. Внешний источник остаётся внешним источником, но его библиографическая запись, идентификатор, ссылка и контекст использования хранятся в GitHub.

## Запись источника

Рекомендуемые поля:

- ID;
- авторы;
- название;
- год;
- тип;
- журнал или издатель;
- DOI, PMID, ISBN или другой устойчивый идентификатор;
- URL;
- дата последней проверки;
- связанные утверждения;
- ограничения;
- статус.

## Статусы

VERIFIED — запись проверена.

PARTIAL — источник существует, но подтверждает только часть утверждения.

UNRESOLVED — требуется дополнительная проверка.

RETRACTED — источник отозван; не использовать как подтверждение без специального исторического контекста.

## Запрет

Не копировать защищённые авторским правом статьи целиком. Хранить библиографические данные, идентификаторы, краткое содержание и необходимые короткие цитаты в пределах допустимого.

До создания отдельного репозитория этот файл является проектной спецификацией, а не самой базой.
