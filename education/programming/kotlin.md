# Kotlin

Рекомендован для Android и JVM. Маршрут: Kotlin, coroutines, Android UI, архитектура приложения, networking и persistence.

## Как выбирать язык

Язык не выбирается по принципу «лучший вообще». Сначала определяется задача, затем платформа, требования к производительности, экосистема библиотек, требования к сопровождению и уровень подготовки.

## Формат обучения

Каждый раздел должен включать минимальный пример, упражнение, типичные ошибки, практический мини-проект и рекомендации по следующему уровню.
