Программирование

Обучение строится от результата: маленькая работающая программа, затем понимание её частей, тестирование, Git и постепенное усложнение.

1. Что установить

  1. Редактор кода или IDE.
  2. Git.
  3. Нужный язык и его пакетный менеджер.
  4. Терминал.
  5. Для проектов с внешними сервисами — файл конфигурации с секретами, который не публикуется в Git.

2. Базовая модель программы

Любую небольшую программу полезно разбирать на четыре вопроса: какие данные поступают, как программа их преобразует, какое решение принимает и какой результат выдаёт.

  1. Создайте минимальный пример.
  2. Запустите его.
  3. Измените одну вещь.
  4. Снова запустите и сравните результат.
  5. Только после этого добавляйте следующую функцию.

3. Python

Подходит для автоматизации, ботов, обработки данных, AI-прототипов и backend.

name = "Yugatn"
print("Привет,", name)

Практика: запросить у пользователя имя, сохранить его в переменную и вывести персональное сообщение. Затем вынести логику в функцию.

4. Веб-разработка

HTML задаёт структуру страницы, CSS отвечает за оформление, JavaScript добавляет поведение. TypeScript добавляет типизацию поверх JavaScript.

Практика: создать страницу с заголовком, карточками, поиском и фильтром, затем проверить её на мобильном экране.

5. Dart и Flutter

Dart используется как язык Flutter. Начинайте с одного экрана: состояние, виджеты, ввод данных, действие пользователя и отображение результата. После этого добавляйте навигацию и сохранение данных.

6. Swift, Kotlin, Rust, Go и SQL

  • Swift: нативные приложения Apple.
  • Kotlin: Android и JVM.
  • Rust: системные задачи с акцентом на безопасность памяти.
  • Go: серверные и инфраструктурные сервисы.
  • SQL: запросы к реляционным базам данных.

Не изучайте все языки одновременно. Сначала закрепите один язык на небольшом проекте.

7. Git и GitHub

  1. Создайте репозиторий.
  2. Сделайте маленькое изменение.
  3. Проверьте diff.
  4. Создайте commit с понятным сообщением.
  5. Отправьте изменения в удалённый репозиторий.
  6. Перед крупным изменением убедитесь, что рабочая версия сохранена.
Никогда не публикуйте пароли, токены API и приватные ключи в репозитории.

Практика

Создайте небольшой проект, который решает одну реальную задачу. Для начала подойдут: переименование файлов, обработка CSV, простой Telegram-бот, статическая веб-страница или программа учёта расходов. Зафиксируйте рабочую версию в Git и только затем расширяйте функциональность.
