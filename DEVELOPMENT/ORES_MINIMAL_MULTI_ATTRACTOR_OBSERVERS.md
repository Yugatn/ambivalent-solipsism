# ORES: минимальный пример с несколькими аттракторами и observer quotient

## Статус

**DEVELOPMENT / Minimal Mathematical Example**

Статусы внутри документа используются строго:
- **DERIVED** — следует из явно заданных определений;
- **NOT_TESTED** — вычислительная реализация ещё не выполнена;
- **CLAIMED** — интерпретация или обобщение, требующее отдельного доказательства.

Цель этого документа — перевести ORES из набора общих определений в минимальную модель, где одновременно видны:
1. несколько устойчивых аттракторов;
2. разные observer mappings;
3. потеря различимости при неинъективном наблюдении;
4. Residual как fibre наблюдения;
5. условие, при котором observer действительно задаёт факторную динамику.

## 1. Конечная динамическая система

Возьмём конечное множество состояний

[
X={a,b,c,u,v}.
]

Динамика задаётся отображением (K:X	o X):

[
K(a)=a,qquad K(b)=b,qquad K(c)=c,
]

[
K(u)=a,qquad K(v)=b.
]

Все состояния имеют тривиальную дискретную топологию.

### DERIVED

Три множества

[
A_1={a},qquad A_2={b},qquad A_3={c}
]

являются неподвижными аттракторами.

Бассейны:

[
B(A_1)={a,u},qquad
B(A_2)={b,v},qquad
B(A_3)={c}.
]

Следовательно, исходная динамика различает три асимптотических режима.

Это не утверждение о физической реальности и не утверждение о человеческой семантике. Это конечная математическая модель.

## 2. Observer 1: полное наблюдение

Пусть

[
Obs_1:X	o Y_1=X
]

и

[
Obs_1(x)=x.
]

### DERIVED

Observer (Obs_1) не склеивает состояния.

Для каждого состояния

[
R_{Obs_1}(y)={y}.
]

Все три аттрактора различимы:

[
Obs_1(A_1)={a},quad
Obs_1(A_2)={b},quad
Obs_1(A_3)={c}.
]

## 3. Observer 2: склейка двух аттракторов

Пусть

[
Y_2={alpha,eta,gamma}
]

и observer задан:

[
Obs_2(a)=alpha,qquad
Obs_2(b)=alpha,qquad
Obs_2(c)=eta,
]

[
Obs_2(u)=alpha,qquad
Obs_2(v)=alpha.
]

Таким образом, (A_1) и (A_2) наблюдательно неразличимы.

### DERIVED

Fibre наблюдения:

[
R_{Obs_2}(alpha)={a,b,u,v},
]

[
R_{Obs_2}(eta)={c},
]

[
R_{Obs_2}(gamma)=arnothing.
]

Для данного observer пустая fibre (gamma) показывает, что кодомен может содержать состояния, которые фактически не реализуются наблюдением. Если требуется сюръективный observer, (gamma) следует удалить из (Y_2).

Наблюдаемый образ аттракторов:

[
Obs_2(A_1)={alpha},
qquad
Obs_2(A_2)={alpha},
qquad
Obs_2(A_3)={eta}.
]

Следовательно, число различимых аттракторных классов уменьшается с трёх до двух.

Это и есть минимальный пример observer-induced loss of distinguishability.

## 4. Факторная динамика для Observer 2

Определим

[
K_2(alpha)=alpha,qquad K_2(eta)=eta.
]

Тогда для каждого (xin X)

[
Obs_2(K(x))=K_2(Obs_2(x)).
]

### DERIVED

Проверка по состояниям:

- (x=a): обе стороны равны (alpha);
- (x=b): обе стороны равны (alpha);
- (x=c): обе стороны равны (eta);
- (x=u): (K(u)=a), поэтому обе стороны равны (alpha);
- (x=v): (K(v)=b), поэтому обе стороны равны (alpha).

Следовательно, (Obs_2) является факторным отображением динамических систем

[
(X,K)longrightarrow(Y_2,K_2).
]

## 5. Observer 3: наблюдение бассейна вместо точного состояния

Пусть

[
Y_3={B_1,B_2,B_3}
]

и

[
Obs_3(a)=Obs_3(u)=B_1,
]

[
Obs_3(b)=Obs_3(v)=B_2,
]

[
Obs_3(c)=B_3.
]

Здесь observer не склеивает разные аттракторы. Он склеивает аттрактор с состояниями его собственного бассейна.

### DERIVED

Fibre:

[
R_{Obs_3}(B_1)={a,u},
]

[
R_{Obs_3}(B_2)={b,v},
]

[
R_{Obs_3}(B_3)={c}.
]

Определим

[
K_3(B_1)=B_1,qquad
K_3(B_2)=B_2,qquad
K_3(B_3)=B_3.
]

Тогда

[
Obs_3circ K=K_3circ Obs_3.
]

Следовательно, (Obs_3) также задаёт факторную динамику.

Этот пример важен потому, что разные observers могут терять разную информацию:

- (Obs_2) теряет различие между двумя аттракторами;
- (Obs_3) сохраняет различие аттракторов, но теряет различие между асимптотическим состоянием и переходным состоянием внутри его бассейна.

## 6. Сравнение observer representations

| Свойство | Исходная система | (Obs_1) | (Obs_2) | (Obs_3) |
|---|---:|---:|---:|---:|
| Различает (A_1,A_2,A_3) | да | да | нет: (A_1sim A_2) | да |
| Различает (a) и (u) | да | да | нет | нет |
| Различает (b) и (v) | да | да | нет | нет |
| Имеет факторную динамику | — | да | да | да |
| Residual может быть нетривиальным | — | нет | да | да |

### DERIVED

Таким образом, «наблюдаемая семантическая структура» не является единственной без указания observer class.

Это не означает, что все representations одинаково информативны. Это означает, что сохранение конкретного инварианта должно быть доказано относительно конкретного отображения.

## 7. Observer-relative attractor

Для любого observer (Obs) определим наблюдаемый образ:

[
A_{Obs}=Obs(A).
]

Важно различать:

[
A

eq
Obs(A)

eq
	ext{attractor of }(Y,K_Y).
]

В данном конечном примере при выполненном факторном условии (Obscirc K=K_Ycirc Obs) наблюдаемые образы действительно являются неподвижными аттракторами соответствующей факторной динамики.

Но в общем случае одно только отображение (Obs:X	o Y) этого не гарантирует.

## 8. Residual как fibre

Для наблюдения (y) задаём

[
R_{Obs}(y)=Obs^{-1}(y).
]

В этой модели Residual не является мистическим остатком и не является автоматически вероятностной величиной.

Он означает множество исходных состояний, совместимых с данным наблюдением.

Например:

[
R_{Obs_2}(alpha)={a,b,u,v}.
]

Если observer сообщает только (alpha), исходное состояние нельзя восстановить однозначно.

Это даёт строгий минимальный смысл формуле:

[
	ext{Model}+	ext{Residual}.
]

Model — наблюдаемое значение (y), Residual — fibre (Obs^{-1}(y)).

Это математическая аналогия с архитектурным принципом, а не доказательство онтологии AS.

## 9. Инварианты и information loss

В конечной модели можно ввести различимость аттракторов как отношение

[
A_iequiv_{Obs}A_j
iff
Obs(A_i)=Obs(A_j).
]

Тогда:

- для (Obs_1) все три класса различны;
- для (Obs_2) (A_1equiv_{Obs_2}A_2);
- для (Obs_3) все три класса различны.

Минимальная мера потери различимости может быть определена здесь как

[
L_{att}(Obs)
=
N_{att}-N_{att}(Obs),
]

где (N_{att}=3), а (N_{att}(Obs)) — число различных наблюдаемых образов аттракторов.

Для этого примера:

[
L_{att}(Obs_1)=0,
]

[
L_{att}(Obs_2)=1,
]

[
L_{att}(Obs_3)=0.
]

### DERIVED

Эта величина является специально выбранной дискретной метрикой потери различимости. Она не является универсальной информационной мерой ORES.

## 10. Контрпример: observer image без factor dynamics

Не всякий observer допускает динамику (K_Y).

Пусть

[
Obs_4(a)=delta,qquad Obs_4(b)=delta,qquad Obs_4(c)=epsilon,
]

[
Obs_4(u)=epsilon,qquad Obs_4(v)=delta.
]

Тогда (Obs_4) склеивает состояния, для которых следующий шаг даёт разные наблюдаемые результаты.

Например,

[
Obs_4(u)=epsilon=Obs_4(c),
]

но

[
Obs_4(K(u))=Obs_4(a)=delta,
]

а

[
Obs_4(K(c))=Obs_4(c)=epsilon.
]

Следовательно, не существует однозначного (K_4(epsilon)), одновременно удовлетворяющего

[
Obs_4circ K=K_4circ Obs_4.
]

### DERIVED

Это минимальный контрпример к слишком сильному утверждению:

> «Любой observer автоматически задаёт динамику observer-space».

Нет. Для этого нужна совместимость observer с динамикой.

## 11. Что модель теперь позволяет проверять

Эта модель задаёт экспериментальный шаблон для следующих вопросов:

1. Как число аттракторов меняется после наблюдательной факторизации?
2. Какие аттракторы становятся неразличимыми?
3. Как меняется размер fibre (R_{Obs}(y))?
4. Какие динамические инварианты сохраняются?
5. Можно ли восстановить исходный класс из наблюдаемого состояния?
6. Когда observer mapping допускает корректную факторную динамику?
7. Какие свойства зависят от observer, а какие сохраняются для целого класса observers?

## 12. Связь с более общей ORES-теорией

Минимальный пример не заменяет гильбертову модель.

Его функция — установить нижний слой, на котором понятия уже имеют строгий смысл:

[
(X,K)
ightarrow
Obs
ightarrow
(Y,K_Y)
ightarrow
R_{Obs}.
]

После этого можно поднимать конструкцию в:

- метрические пространства;
- топологические динамические системы;
- Banach/Hilbert spaces;
- дифференцируемую динамику;
- линеаризацию и спектр;
- SemCat₂;
- observer functors;
- transport и holonomy.

Такой порядок уменьшает риск того, что более высокий категориальный язык будет скрывать недоказанные предпосылки нижнего уровня.

## Итог

Минимальная модель показывает принципиальное различие между:

1. динамикой самой системы;
2. наблюдаемым представлением;

Именно это различие должно стать тестовым фундаментом ORES перед дальнейшим усложнением теории.
