# ORES: непрерывная многoаттракторная модель и observer quotient

## Назначение

Этот документ поднимает минимальную конечную модель ORES на непрерывное состояние. Цель не в том, чтобы объявить общую теорему для всех динамических систем, а в том, чтобы проверить, сохраняются ли ключевые различия на конкретной гладкой модели:

1. исходная динамика;
2. несколько устойчивых аттракторов;
3. бассейны притяжения;
4. observer mapping;
5. факторная динамика;
6. потеря различимости аттракторов;
7. Residual как множество состояний, совместимых с наблюдением.

Вычислительная реализация находится в `EXPERIMENTS/ORES_CONTINUOUS_MULTI_ATTRACTOR.py`.

## 1. Динамическая система

Рассмотрим потенциал

[
V(x)=x^2(x^2-1)^2.
]

Определим дискретную динамику градиентного типа

[
K(x)=x-eta V'(x),
]

где

[
V'(x)=2x(x^2-1)(3x^2-1),
]

а в эксперименте (eta=0.05).

Исследуемый интервал:

[
X=[-1.2,1.2].
]

Это конкретная модель, а не утверждение о всех ORES-системах.

## 2. Устойчивые фиксированные точки

Точки

[
x=-1,qquad x=0,qquad x=1
]

являются фиксированными точками, поскольку (V'(x)=0) в этих точках.

Для анализа локальной устойчивости:

[
K'(x)=1-eta V''(x).
]

Вторая производная имеет вид

[
V''(x)=2(15x^4-12x^2+1).
]

Поэтому

[
V''(-1)=8,qquad V''(0)=2,qquad V''(1)=8.
]

При (eta=0.05):

[
|K'(-1)|=|1-0.05cdot8|=0.6<1,
]

[
|K'(0)|=|1-0.05cdot2|=0.9<1,
]

[
|K'(1)|=|1-0.05cdot8|=0.6<1.
]

### DERIVED

Все три фиксированные точки локально устойчивы для выбранного параметра.

Следовательно, конкретная модель содержит как минимум три локально устойчивых режима.

## 3. Численная проверка бассейнов

Эксперимент использует 241 начальное состояние с шагом (0.01) на интервале от (-1.2) до (1.2) и выполняет 2000 итераций.

Получено:

| Аттрактор | Число начальных состояний |
|---|---:|
| (-1) | 63 |
| (0) | 115 |
| (+1) | 63 |

Максимальное расстояние конечного состояния до ближайшего из трёх аттракторов составило приблизительно

[
2.22cdot10^{-16}.
]

### OBSERVED

Для выбранной сетки начальных условий и параметра (eta=0.05) численная итерация подтверждает разделение исследуемого интервала на три бассейна притяжения и сходимость к соответствующему устойчивому состоянию.

Это наблюдение относится только к выполненному вычислительному эксперименту. Оно не является доказательством глобальной сходимости для всех (xin X).

## 4. Observer полного состояния

Сначала рассмотрим тождественное наблюдение

[
Obs_{mathrm{id}}(x)=x.
]

Оно не склеивает состояния и поэтому сохраняет различимость трёх аттракторов.

Для него:

[
L_{att}(Obs_{mathrm{id}})=0.
]

## 5. Симметричный observer

Теперь введём

[
Obs_{mathrm{abs}}(x)=|x|.
]

Этот observer теряет информацию о знаке состояния.

Для трёх аттракторов:

[
Obs_{mathrm{abs}}(-1)=1,
]

[
Obs_{mathrm{abs}}(0)=0,
]

[
Obs_{mathrm{abs}}(1)=1.
]

Следовательно, два исходных аттрактора (-1) и (+1) становятся одним наблюдаемым классом.

### DERIVED

Для данной модели число различимых аттракторных классов уменьшается с трёх до двух.

Если использовать ранее введённую дискретную величину

[
L_{att}(Obs)=N_{att}-N_{att}(Obs),
]

то

[
L_{att}(Obs_{mathrm{abs}})=3-2=1.
]

## 6. Почему здесь действительно существует факторная динамика

Одного observer mapping недостаточно. Необходимо проверить совместимость с динамикой:

[
Obscirc K=K_Ycirc Obs.
]

Для данного observer определим

[
K_Y(y)=|K(y)|.
]

Поскольку (K) является нечётным отображением,

[
K(-x)=-K(x),
]

получаем

[
|K(x)|=|K(|x|)|.
]

Следовательно,

[
Obs_{mathrm{abs}}(K(x))
=
K_Y(Obs_{mathrm{abs}}(x)).
]

### DERIVED

Для данной модели ((X,K)) действительно существует факторная динамика на наблюдаемом пространстве.

Это важный результат, потому что он показывает: потеря различимости двух аттракторов не обязательно разрушает динамическую структуру. При наличии совместимости наблюдение может индуцировать собственную динамическую систему.

## 7. Residual как fibre

Для наблюдаемого значения (y) определим

[
R_{Obs}(y)=Obs^{-1}(y).
]

Для абсолютного observer:

[
R_{Obs_{mathrm{abs}}}(y)={-y,y}
]

для (y>0), а

[
R_{Obs_{mathrm{abs}}}(0)={0}.
]

Например,

[
R_{Obs_{mathrm{abs}}}(1)={-1,1}.
]

Это даёт непрерывный пример того же принципа, который был получен ранее на конечном множестве: наблюдаемое значение не обязано однозначно определять исходное состояние.

Однако fibre не следует автоматически называть «информацией о реальности». В математической модели это множество состояний, совместимых с конкретным observer output.

## 8. Новый результат относительно конечной модели

В конечной модели потеря различимости была задана вручную таблицей observer states.

В непрерывной модели она возникает из симметрии пространства состояний и динамического закона.

Это позволяет сформулировать более содержательный исследовательский вопрос:

> Какие свойства динамики сохраняются после факторизации по симметрии observer?

В данном примере сохраняется факторная динамика, но теряется знак состояния и различие между двумя зеркальными устойчивыми аттракторами.

## 9. Граница результата

Нельзя делать следующий переход без дополнительного доказательства:

> «Если observer склеивает симметричные состояния, то факторная динамика всегда существует».

Это неверно без условия совместимости.

Также нельзя автоматически утверждать:

> «Любой наблюдаемый образ аттрактора является аттрактором observer-space».

Необходимо отдельно доказать существование induced dynamics и затем проверить свойства соответствующего множества.

## 10. Связь с ORES

Теперь ORES имеет два независимых тестовых уровня.

### Конечный уровень

Он проверяет логическую структуру observer quotient, fibres, factor dynamics и контрпримеров.

### Непрерывный уровень

Он проверяет те же различия на конкретной нелинейной динамической системе с несколькими устойчивыми аттракторами.

Это создаёт более строгую последовательность дальнейшего развития:

1. конечные системы;
2. конкретные непрерывные системы;
3. общий метрический результат;
4. Banach/Hilbert пространства;
5. наблюдательные классы;
6. спектральные инварианты;
7. категориальная формализация.

Переход к следующему уровню должен происходить только после проверки соответствующего нижнего уровня.

## 11. Статусы

**DERIVED:** локальная устойчивость трёх фиксированных точек для выбранной модели и параметра.

**OBSERVED:** численная классификация 241 начального состояния и факторная совместимость абсолютного observer на проверенной выборке.

**CLAIMED:** возможное обобщение механизма на классы симметричных динамических систем требует отдельной теоремы.

**NOT_TESTED:** глобальная теорема о бассейнах на всём интервале, устойчивость к изменению (eta), многомерные модели и Hilbert-space обобщение.

**CONFLICTED:** отсутствует для результатов данного эксперимента.

## 12. Следующий математический этап

Следующим шагом следует не добавлять ещё один абстрактный категориальный слой, а сформулировать и проверить общий результат для observer factorization.

Минимальная целевая теорема должна отвечать на вопрос:

> При каких условиях непрерывное отображение (Obs:X	o Y) и динамика (K:X	o X) индуцируют однозначную непрерывную динамику (K_Y:Y	o Y)?

После этого отдельно следует исследовать, при каких условиях образ компактного аттрактора (Obs(A)) является аттрактором факторной системы.

Только затем имеет смысл возвращаться к SemCat₂ и observer functor.

## Итог

Непрерывный пример подтверждает, что observer-relative loss of distinguishability можно исследовать без обращения к метафизике и без предварительного категориального аппарата.

В конкретной модели три устойчивых аттрактора существуют в исходном пространстве. Абсолютный observer склеивает два из них, но при этом сохраняет факторную динамику. Residual становится нетривиальным fibre исходных состояний, совместимых с наблюдением.

Это делает непрерывную модель следующим рабочим фундаментом ORES перед формулировкой общего observer-factor theorem.
