# Anti-Replay Evidence

This directory is reserved for reproducible evidence produced by the assurance pipeline.

Expected evidence artifacts:
- model-check.txt — TLC result for AntiReplay.tla;
- broken-model-check.txt — expected TLC counterexample for AntiReplay_Broken.tla;
- attack-trace.json — normalized adversarial trace;
- test-results.json — reference and adversarial test results.

Evidence is generated by CI or a reproducible local command. It must not be manually edited to convert a failure into a pass.

A successful model check establishes only the properties encoded in the model under its assumptions. It does not prove the production implementation or the entire Eugene Messenger system.
