Metrics & Benchmarks

Измерения не являются security proof. Их задача — сделать инженерные свойства воспроизводимыми и обнаруживать регрессии.

МетрикаЧто измеряетсяКонтекст
Handshake latencyВремя установления сессииУстройство, сеть, версия протокола
Message latencyEnd-to-end deliveryРазмер сообщения и число relay hops
Crypto overheadРазмер и CPU overheadТип payload, session state
Relay throughputСообщений/байт в секундуЧисло concurrent sessions
Recovery timeВремя до восстановления доверияКоличество участников N-of-M
Metadata exposureКакие поля доступны каждому trust domainНормальный и degraded mode

Правило воспроизводимости

Каждый benchmark должен фиксировать версию кода, конфигурацию, hardware profile, network conditions и метод измерения. Нельзя сравнивать результаты без одинакового experimental protocol.
