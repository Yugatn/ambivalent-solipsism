Единый реестр трассируемости. Каждое security claim должно быть связано с конкретной спецификацией, моделью, тестом и статусом реализации.

Правило трассируемости

Claim без test oracle считается гипотезой. Реализация без соответствующей спецификации считается prototype implementation. Модель без conformance не доказывает свойства конкретного бинарника.
