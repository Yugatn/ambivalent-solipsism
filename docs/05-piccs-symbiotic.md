# 05. PICCS, SymbiontOS и субъектность

Онтология «Душа + Транспорт» не заменяет формальную архитектуру PICCS и SymbiontOS. Она задаёт для неё философский boundary.

## 1. Subject Non-Reduction

Профиль, score, prediction, StateVector, психометрический результат или AI-модель являются представлениями. Они не получают автоматически статус самого субъекта.

## 2. Authority Separation

Классификация не создаёт автоматически полномочие. Даже если система правильно обнаружила состояние, из этого не следует право системы самостоятельно вмешиваться.

## 3. Context Sovereignty

Информация, полученная в одном контексте, не должна автоматически становиться основанием действия в другом контексте.

## 4. Residual Preservation

Система должна сохранять возможность UNKNOWN. Если модель не различает два состояния, это не основание искусственно выбирать одно из них только ради завершения процедуры.

## 5. Минимально необходимое вмешательство

При сопоставимой ожидаемой эффективности рассматривается менее инвазивный и более обратимый вариант. Это инженерный принцип ограниченного вмешательства, а не универсальный математический критерий добра.

## 6. Связь с существующей архитектурой

Эти положения согласуются с уже существующими слоями PICCS, EthicalAudit, DEFT, CTO, Event Fabric, Symbiont Protocol и SymbiontOS.

Новая онтология добавляет смысловой boundary и не отменяет формальные требования доказательности.
