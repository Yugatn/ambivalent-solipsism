# Реестр постатейной верификации v3

## Назначение

Третий проход переносит проверку от отдельных прав к системным механизмам: государственная власть, наблюдаемость, распределённая обратная связь, память государства и защита информационной инфраструктуры.

Контрольный источник: BOOK/11_CONSTITUTION.md.

## Государство как наблюдаемая система

Результат: VERIFIED AS MODEL / PROCEDURAL NEEDS_REVIEW.

Сохранён принцип, согласно которому государство должно быть способно наблюдать собственные последствия и получать независимые сигналы о состоянии общества.

Усовершенствование: наблюдаемость должна включать не только сбор сигнала, но и путь его проверки, публикацию методологии, фиксацию неопределённости и возможность исправления ошибочного вывода.

## Прямой информационный канал граждан

Результат: MODEL / PROCEDURAL NEEDS_REVIEW.

Канал обратной связи не должен превращаться в канал автоматического наказания.

Зафиксировано разделение:

сигнал → проверка → решение → исполнение → пересмотр.

Это соответствует уже сформированному принципу detection != verdict.

## Распределённая сенсорная сеть

Результат: MODEL / UNRESOLVED.

Гражданские сообщения могут выступать источником сигналов, но не должны автоматически считаться доказательствами.

Необходимы:

- защита от координированной манипуляции;
- защита от ответного преследования;
- оценка репрезентативности;
- независимая проверка;
- защита персональных данных;
- фиксация уровня неопределённости.

## Защита от информационного пузыря власти

Результат: VERIFIED AS MODEL.

Сохранён принцип независимых источников информации для высших органов управления.

Усовершенствование: «независимый источник» не должен определяться только организационным происхождением. Необходимы разнообразие методов, источников и каналов проверки.

## Государственный dashboard

Результат: VERIFIED AS MODEL / IMPLEMENTATION NEEDS_REVIEW.

Сохранён принцип отображения:

- источника;
- методологии;
- периода;
- временного ряда;
- неопределённости;
- регионального распределения.

Усовершенствование: показатель без контекста не должен использоваться как самостоятельное основание для санкции или кадрового решения.

## Раннее обнаружение

Результат: VERIFIED AS MODEL.

Раннее обнаружение является сигналом для дополнительной проверки, а не доказательством нарушения.

Добавлено различие между:

- weak signal;
- corroborated signal;
- established finding.

## Государство как самокорректирующаяся система

Результат: VERIFIED AS MODEL.

Самокоррекция должна включать:

- признание ошибки;
- независимую проверку;
- исправление;
- сохранение истории;
- анализ причины;
- предотвращение повторения.

Удаление неудобного исторического следа не считается исправлением.

## Защита информационной инфраструктуры

Результат: VERIFIED AS MODEL / SECURITY NEEDS_REVIEW.

Информационная инфраструктура государства должна быть защищена от захвата одной группой, но меры защиты сами не должны становиться основанием для монополизации информации.

## Лидер как наблюдатель, а не единственный центр истины

Результат: VERIFIED AS MODEL.

Лидер может получать широкий обзор значимых процессов, но не должен становиться единственным источником интерпретации.

Усовершенствование: система должна сохранять независимые каналы проверки даже при совпадении позиции лидера и большинства институтов.

## State Memory

Результат: VERIFIED AS MODEL.

Государственная память должна хранить не только решения, но и основания, версии данных, неопределённость, исправления и историю пересмотров.

Это связывается с правом на исправление модели и принципом независимого пересмотра.

## Новые инварианты

### INV-GS-1: Signal Is Not Verdict

Сигнал, сообщение или аномалия не являются доказанным нарушением.

### INV-GS-2: Observation Is Not Authority

Наличие доступа к информации не создаёт автоматически права принимать решение.

### INV-GS-3: Methodology Before Metric

Значимый показатель должен сопровождаться происхождением данных, методологией и ограничениями интерпретации.

### INV-GS-4: Memory Includes Correction

Исправленная версия не должна уничтожать возможность восстановить историю ошибки и её исправления.

### INV-GS-5: Distributed Observation, Distributed Review

Распределённый сбор сигналов требует распределённой проверки, иначе сенсорная сеть может стать централизованным каналом манипуляции.

## UNRESOLVED

Остаются открытыми:

- точная модель Совета мудрых и умных;
- границы прямого информационного канала;
- правила защиты гражданских информаторов;
- критерии репрезентативности распределённых сигналов;
- архитектура государственного dashboard;
- пределы наблюдения за значимыми процессами;
- процедура чрезвычайного режима.

Этот документ не меняет Конституцию и не делает существующую политическую систему описанием реальности. Он фиксирует архитектурную модель проекта.
