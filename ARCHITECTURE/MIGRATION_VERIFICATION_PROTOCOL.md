# Протокол верификации тематической миграции

## Назначение

После этапа COPIED тематический узел не считается завершённым. Его необходимо сопоставить с контрольным источником и связанными узлами.

Цель проверки — не подтвердить заранее выбранную структуру, а обнаружить потерю смысла, дублирование, противоречие или ошибочную смену статуса.

## 1. Матрица проверки

Для каждого положения фиксируются:

| Поле | Содержание |
|---|---|
| Source | исходный фрагмент и файл |
| Target | тематический узел |
| Meaning | сохранённый смысл |
| Status | CANON, MODEL, PROPOSED, RESEARCH, UNRESOLVED и др. |
| Links | связанные документы |
| Conflict | обнаруженное противоречие |
| Loss | отсутствующий материал |
| Decision | результат проверки |

## 2. Типы результата

### VERIFIED
Смысл сохранён, статус не изменён, связи проверены, существенных противоречий не обнаружено.

### NEEDS_REVIEW
Есть неоднозначность, неполный контекст или недостаточно данных для подтверждения.

### CONFLICT
Обнаружены положения, которые нельзя одновременно считать действующими без дополнительного решения.

### LOSS
Часть существенного смысла исходного материала не перенесена.

### DUPLICATE
Материал повторяет уже существующий узел без добавленной функции.

### STATUS_DRIFT
При переносе авторское предположение, модель или нерешённый вопрос ошибочно стал каноном либо наоборот.

## 3. Запрет автоматического повышения статуса

Перенос текста не повышает его эпистемический или нормативный статус.

PROPOSED не становится CANON только потому, что появился в тематическом разделе.
MODEL не становится установленным фактом.
RESEARCH не становится доказательством.
UNRESOLVED не становится решённым положением без отдельного основания.

## 4. Проверка связей

Для каждого узла проверяются:

- ссылка на контрольный источник;
- обратная связь из контрольного источника или матрицы;
- связи с соседними тематическими узлами;
- связи в KNOWLEDGE_GRAPH.md;
- зависимые проекты;
- научные и критические материалы;
- навигация.

Связь, существующая только в одном направлении, помечается как требующая проверки.

## 5. Проверка противоречий

Особое внимание уделяется конфликтам между:

- автономией и безопасностью;
- свободой и ограничением;
- экономической эффективностью и развитием;
- наблюдаемостью государства и приватностью граждан;
- ИИ-автоматизацией и человеческим контролем;
- защитой детей и их формирующейся автономией;
- солидарностью и правом собственности;
- чрезвычайными полномочиями и обратимостью;
- коллективным интересом и Subject Non-Reduction.

Противоречие не устраняется переписыванием одного из положений без фиксации причины.

## 6. Минимальная единица проверки

Единицей проверки является не файл целиком, а отдельное смысловое положение.

Большой документ может содержать одновременно VERIFIED положения, NEEDS_REVIEW, CONFLICT и UNRESOLVED.

Поэтому один статус файла не должен скрывать неоднородность его содержания.

## 7. Проверка пространства возможностей

Для положений, связанных с ИИ, государством, экономикой, медициной, образованием или информацией, дополнительно фиксируется:

- какие возможности субъекта расширяются;
- какие сужаются;
- кто принимает решение;
- на каком основании;
- насколько последствия обратимы;
- какие альтернативы сохраняются;
- какие неизвестные остаются.

Это не заменяет оценку вреда и не превращает пространство возможностей в единственный KPI.

## 8. Решение по результату

После проверки материал получает одно из состояний:

COPIED, LINKED, VERIFIED, NEEDS_REVIEW, CONFLICT, LOSS или DUPLICATE.

Только VERIFIED может стать основанием для дальнейшего рассмотрения DUPLICATE_CANDIDATE.

## 9. История

Каждая существенная корректировка должна сохранять:

- что изменено;
- почему;
- какой источник использован;
- какой статус был до изменения;
- какой статус установлен после;
- какие связанные документы затронуты.

## 10. Контрольный принцип

> Перенос сохраняет происхождение. Верификация проверяет смысл. Критика проверяет устойчивость. Удаление является отдельным решением.

Этот протокол расширяет ARCHITECTURE/MIGRATION_MATRIX.md и не заменяет контрольный источник Конституции.
