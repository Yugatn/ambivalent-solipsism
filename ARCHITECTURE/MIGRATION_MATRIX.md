# Матрица безопасной реструктуризации

## Назначение

Этот документ управляет постепенным переносом материала из исторической структуры в оптимизированную структуру.

**Ничего не удаляется только потому, что найдено более подходящее место.**

## Статусы миграции

- `LEGACY` — исходное расположение сохранено;
- `COPIED` — необходимый материал скопирован в целевой раздел;
- `LINKED` — установлены двусторонние связи;
- `VERIFIED` — проверены смысл, ссылки, навигация и зависимости;
- `DUPLICATE_CANDIDATE` — подтверждено, что исходный материал больше не является уникальным источником;
- `DEPRECATED` — исходный материал помечен как устаревающий;
- `REMOVED` — удалён только после отдельной проверки.

## Правило перехода

`LEGACY` → `COPIED` → `LINKED` → `VERIFIED` → `DUPLICATE_CANDIDATE` → `DEPRECATED` → `REMOVED`

Переход через несколько состояний за один шаг не допускается.

## Проверка перед удалением

Перед `REMOVED` необходимо проверить:

- весь уникальный смысл сохранён;
- канонические формулировки сохранены;
- статус материала не изменён случайно;
- внутренние ссылки обновлены;
- внешние ссылки обновлены;
- навигация работает;
- зависимые документы не потеряли контекст;
- Git history сохраняет происхождение;
- отсутствуют незакрытые связи, которые указывали только на старый файл;
- Закон развития и связанные ограничения не потеряны;
- критические и UNRESOLVED-фрагменты сохранены.

## Приоритет миграции

В первую очередь проверяются:

1. философия;
2. идеология и законы;
3. конституционные материалы;
4. архитектурные принципы;
5. исследования и критика;
6. проекты;
7. эксперименты;
8. оформление и технические дубликаты.

## Особое правило для Конституции

`BOOK/11_CONSTITUTION.md` является крупным источником нормативного материала. Его нельзя удалять или дробить до завершения отдельного аудита всех положений.

Сначала создаются тематические представления и связи, затем проверяется, что каждое положение имеет одно определённое каноническое место.

До этого исходная Конституция остаётся сохранённой.

## Цель

Результатом должна стать не меньшая по содержанию система, а система, в которой:

- один смысл имеет понятный источник;
- производные представления не конкурируют с источником;
- история сохраняется;
- переходы обратимы;
- удаление становится последним, а не первым шагом.
