# Content Audit

## Purpose

Content Audit проверяет не наличие файлов, а сохранение смысла при миграции.

## Migration classes

- **migrated** — содержание перенесено без существенной потери;
- **refined** — содержание перенесено и формализовано несколькими связанными модулями;
- **merged** — содержание объединено с другим модулем без потери самостоятельного принципа;
- **index** — навигационный индекс;
- **pending** — требуется дополнительная сверка.

## Required checks

Для каждого legacy-файла проверяются назначение, нормативные принципы, доменные понятия, ограничения, lifecycle, evidence, audit-требования, связанные документы и отсутствие противоречий.

Если один legacy-фрагмент распределён по нескольким новым файлам, это считается корректной миграцией при наличии traceability.

## Current checkpoint

Файловое покрытие: **100%**.

Семантическое покрытие проверяется отдельно.

Legacy-файлы сохраняются до окончания content-level audit.
