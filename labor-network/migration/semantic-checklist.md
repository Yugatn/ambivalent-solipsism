# Semantic Migration Checklist

## Purpose

Этот checklist используется после файлового переноса для проверки сохранения смысла.

## Checks

### Governance
- principles
- authority
- human review
- accountability

### Domain
- subject
- work
- employer
- professional profile
- education
- projects
- remuneration
- self-employment

### Lifecycle
- opportunity
- engagement
- evidence
- decision
- permission
- dispute
- work

### Safety
- security
- privacy
- consent
- abuse prevention
- reversibility
- incident response

### Evidence
- provenance
- verification
- challenge
- trust

### Federation
- API contract
- schema contract
- federation boundaries
- state interface
- interoperability

### Operations
- support
- regional development
- transport
- social protection
- solidarity
- public programs

## Classification

Each legacy block is classified as:

- preserved;
- refined;
- merged;
- intentionally indexed;
- pending.

No legacy source is deleted while any substantive block is pending.

## Completion condition

Semantic migration is complete only when all substantive blocks are classified and every non-trivial block has a destination in the new architecture.
