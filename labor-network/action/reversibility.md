# Reversibility

Для каждого high-impact Action заранее определяется:

- можно ли отменить;
- как восстановить состояние;
- кто имеет полномочие;
- какие зависимые эффекты нужно пересмотреть;
- какая компенсация требуется при невозможности полного rollback.

Необратимость должна быть явным свойством действия, а не скрытым эффектом реализации.
