# Decision Log

Для каждого существенного Decision сохраняются:

- входной context;
- используемые Evidence;
- policy version;
- impact class;
- результат;
- review;
- применённый Action;
- последующие corrections.

Лог должен позволять восстановить причинную последовательность без необходимости доверять текущему состоянию как единственному источнику.
