# Региональная экономика и распределение возможностей

СТСеть может использовать агрегированные данные для выявления несоответствия между возможностями, навыками и инфраструктурой региона.

## 1. Что анализируется

Например:

- вакансии;
- профессиональные компетенции;
- обучение;
- транспорт;
- стоимость перемещения;
- инфраструктура;
- локальные проекты.

## 2. Что не анализируется автоматически

Региональный экономический контур не должен создавать универсальный рейтинг полезности гражданина.

Нельзя сводить:

- налоговый вклад;
- доход;
- производительность;
- участие в проектах

в единую оценку человеческой ценности.

## 3. Инвестиционный сигнал

Если регион обнаруживает устойчивый дефицит инфраструктуры, это может стать основанием для инвестиционного проекта.

Таким образом, сеть показывает не только «кого не хватает», но и «чего не хватает среде».

## 4. Цикл развития

Региональная программа проходит цикл:

**наблюдение, гипотеза, проект, реализация, измерение результата, проверка побочных эффектов, пересмотр.**

## 5. Необратимые решения

Региональная аналитика не должна автоматически запускать необратимые решения в отношении отдельных субъектов.

Для индивидуального воздействия требуется отдельный процесс и основание.
