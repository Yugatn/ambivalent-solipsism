# Государственный интерфейс СТСети

Государственный контур СТСети предназначен для взаимодействия субъекта с государственными услугами и программами развития.

Он не должен превращать трудовую сеть в систему непрерывного государственного наблюдения.

## 1. Принцип государство как сервис

Государство предоставляет:

- инфраструктуру;
- социальные гарантии;
- образование;
- трудовые сервисы;
- защиту прав;
- официальную информацию;
- программы развития.

СТСеть может выступать интерфейсом доступа к этим возможностям, но не заменяет государственные полномочия.

## 2. Прямой канал субъекта

Субъект должен иметь возможность:

- получить официальную информацию;
- увидеть статус обращения;
- представить документы;
- оспорить решение;
- получить объяснение;
- обратиться без обязательного прохождения всех несущественных промежуточных уровней.

## 3. Государственное решение

Если решение существенно влияет на трудовую возможность, должны быть известны:

- орган или должностное лицо;
- основание;
- применённое правило;
- срок;
- порядок обжалования.

Автоматическая обработка не снимает ответственности с государственного субъекта, принявшего решение.

## 4. Минимизация данных

Государственный сервис получает только данные, необходимые для конкретной функции, в пределах закона.

Наличие технической возможности объединить базы не является достаточным основанием для объединения.

## 5. Разделение функций

Данные для:

- выплаты;
- налогообложения;
- обучения;
- трудового подбора;
- статистики

не должны автоматически использоваться для других целей.

## 6. Независимость

СТСеть не должна становиться единственным каналом взаимодействия с государством.

Критически важные права должны иметь альтернативные способы реализации в пределах действующего права.

## 7. Аудит

Существенные автоматизированные процессы должны иметь журнал:

- правила;
- версии;
- входных данных;
- решения;
- ответственного контура;
- исправлений.
