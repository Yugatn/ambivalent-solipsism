# Event Layer

Event фиксирует произошедшее изменение или факт взаимодействия.

Event не является текущим состоянием.

## Требования

Каждое существенное событие должно иметь:

- идентификатор;
- тип;
- субъекта и инициатора;
- время;
- контекст;
- provenance;
- correlation id;
- schema version.

Повторная обработка одного события не должна создавать дополнительный эффект.
