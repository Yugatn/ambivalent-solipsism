# Профессиональный профиль

Профессиональный профиль представляет проверяемую часть профессиональной истории субъекта.

Он может содержать:

- образование;
- квалификацию;
- компетенции;
- трудовой опыт;
- дополнительные курсы;
- портфолио;
- достижения;
- рекомендации;
- профессиональные интересы;
- результаты PROF-MAP;
- добровольно предоставленные психодиагностические материалы.

## Подтверждение компетенции

Для каждой компетенции желательно хранить:

- источник утверждения;
- подтверждающего субъекта;
- дату;
- уровень;
- свидетельство или результат деятельности;
- срок актуальности;
- возможность повторной оценки.

Заявленная компетенция не становится подтверждённой только из-за записи в резюме.

## Видимость

Каждый тип информации имеет собственный уровень доступа.

Работодатель получает только тот объём данных, который необходим для соответствующего трудового взаимодействия.

> **Профессиональный профиль — модель субъекта, а не субъект.**
