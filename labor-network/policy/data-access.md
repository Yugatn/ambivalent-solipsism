# Data Access Policy

Доступ к данным определяется целью, полномочием и минимально необходимым scope.

Наличие данных в системе не означает право их просмотра, копирования или передачи.

Каждый существенный доступ должен быть трассируемым.

Расширение набора данных не расширяет автоматически полномочия.
