# Recruitment Policy

Recruitment Policy определяет допустимое использование профессионального профиля и Evidence при подборе.

Система должна различать:

- обязательное требование;
- предпочтение;
- проверяемый факт;
- неопределённость;
- субъективное мнение.

Автоматический результат не должен маскировать неопределённость под факт.

Для существенного отказа должен существовать reason code и предусмотренный механизм пересмотра.
