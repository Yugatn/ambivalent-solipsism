# Evidence Challenge

Субъект или уполномоченный участник может оспорить предусмотренное для challenge утверждение.

Challenge:

1. не стирает исходную запись;
2. фиксируется отдельным событием;
3. запускает определённый процесс review;
4. может привести к изменению статуса Evidence;
5. позволяет обнаружить зависимые решения.
