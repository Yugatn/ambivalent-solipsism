# Самозанятые и профессиональные услуги

СТСеть включает не только классические трудовые отношения.

Профессиональная карточка может использоваться самозанятыми, мастерами и независимыми специалистами.

Направления:

- репетиторство;
- обучение;
- ремонт;
- электрика;
- сантехника;
- сварка;
- строительство;
- обслуживание;
- ремонт компьютеров и смартфонов;
- творческие услуги;
- другие профессиональные услуги.

Карточка может содержать:

- специализацию;
- опыт;
- навыки;
- портфолио;
- выполненные работы;
- отзывы;
- образование;
- подтверждение квалификации.

Налоговая информация используется только в пределах предусмотренного правового основания и не превращается в оценку личности.
