# Self-Employment

Self-Employment описывает самостоятельную профессиональную деятельность субъекта.

Сеть должна поддерживать самостоятельный путь без обязательного перехода в отношения Employer–Employee.

Минимальные элементы:

- offer;
- service;
- engagement;
- payment;
- evidence;
- support;
- exit.
