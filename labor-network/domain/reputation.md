# Reputation

Reputation — совокупность проверяемых сведений о профессиональном взаимодействии, а не единый балл человека.

Система должна различать:

- факт действия;
- подтверждение;
- отзыв;
- спор;
- контекст.

Наличие отрицательного события не должно автоматически становиться глобальной характеристикой субъекта.
