# Privacy and State Integration

Государственная или межорганизационная интеграция должна использовать минимально необходимый объём данных.

Доступ определяется:

- purpose;
- authority;
- scope;
- validity;
- policy.

Интеграция не должна создавать универсальный профиль субъекта.

Передача данных должна быть трассируема, а предусмотренные законом права субъекта должны сохраняться.
