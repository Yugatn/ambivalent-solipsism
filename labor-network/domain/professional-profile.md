# Professional Profile

Professional Profile представляет текущую профессиональную конфигурацию субъекта.

Профиль не является окончательным описанием человека.

Он может включать:

- skills;
- experience;
- education;
- interests;
- preferred conditions;
- verified evidence;
- development goals.

Каждый существенный элемент должен иметь источник, дату и контекст.

Профиль может изменяться без уничтожения предыдущей истории.
