# Профессиональный профиль

Профессиональный профиль представляет проверяемую часть профессиональной истории субъекта. Он помогает взаимодействовать с работодателями, образовательными организациями и профессиональными сервисами, но не является полной моделью человека.

## Состав профиля

Он может содержать:

- образование;
- квалификацию;
- компетенции;
- трудовой опыт;
- дополнительные курсы;
- портфолио;
- достижения;
- рекомендации;
- профессиональные интересы;
- результаты PROF-MAP;
- добровольно предоставленные психодиагностические материалы.

## Состояния информации

Каждое существенное утверждение желательно различать по состоянию:

- заявлено субъектом;
- подтверждено документом;
- подтверждено организацией;
- подтверждено результатом деятельности;
- получено из внешнего источника;
- оспаривается;
- утратило актуальность.

Подтверждение показывает происхождение и способ проверки конкретного утверждения, а не абсолютную истинность.

## Подтверждение компетенции

Для каждой компетенции желательно хранить источник утверждения, подтверждающего субъекта, дату, уровень, свидетельство или результат деятельности, срок актуальности и возможность повторной оценки.

Заявленная компетенция не становится подтверждённой только из-за записи в резюме.

## Контекст компетенции

Одна компетенция может иметь различную актуальность в разных задачах. Поэтому следует учитывать контекст её применения.

## Видимость

Каждый тип информации имеет собственный уровень доступа. Работодатель получает только объём данных, необходимый для соответствующего трудового взаимодействия.

Чувствительные психологические, медицинские и иные специальные категории данных не должны автоматически включаться в обычный кадровый профиль.

> **Профессиональный профиль — модель субъекта, а не субъект.**

## Право на исправление

Субъект может оспорить фактическую запись, добавить контекст или указать на изменение обстоятельств.

Исправление не должно стирать факт изменения записи там, где история происхождения имеет значение для аудита.

## Переносимость

Профиль должен быть переносимым между организациями и сервисами настолько, насколько это допускают правовые основания и настройки субъекта.

Переносимость не означает автоматическую передачу всех данных новому работодателю.
