# Domain Layer

Доменный слой сохраняет предметную семантику Социальной Трудовой Сети отдельно от инфраструктуры.

## Основные домены

- Subject
- Opportunity
- Engagement
- Professional Profile
- Evidence
- Development
- Support
- Employer
- Regional Development
- Reputation
- Self-Employment

Доменная модель не должна зависеть от конкретной БД, UI или транспортного протокола.
