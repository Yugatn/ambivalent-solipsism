# Level 1 Fixtures

The six regression classes are represented as JSON authoring fixtures.

- F: structural/context reference without validity dependency
- G: semantic and generative dependency without validity dependency
- H: mandatory validity dependency with independent witness
- I: outside T★
- L: VALID to UNKNOWN after removal
- M: dependency through certificate closure

CBOR files are generated by the reference implementation. Hand-authored binary CBOR is deliberately avoided.

Expected outputs are normative and are compared after canonical JSON normalization.

M additionally requires a negative control: a deliberately naive checker without certificate closure MUST fail M.
