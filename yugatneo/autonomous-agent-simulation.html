YUGATNEO / EPISTEMIC RESEARCH / AAS v0.1

Autonomous Agent Simulation

Изолированный исследовательский слой Yugatneo, предназначенный для генерации adversarial traces, поиска контрпримеров и исследования постепенной эрозии конституционных инвариантов.

Статус: исследовательская спецификация. AAS не является authority, consensus-механизмом, источником истины или автоматическим механизмом блокировки. Он производит evidence, которое может быть использовано Constitutional Check.

1. Онтологический статус

AAS существует в sandbox-среде. Его состояние не является состоянием основной сети, а действия агентов не имеют экономических или governance-последствий для mainnet.

Agent ≠ Validator Agent ≠ CheckerAuthority Agent ≠ Governance Participant Simulation State ≠ Mainnet State Simulation Trace ≠ Mainnet Evidence of Fact

Результат симуляции имеет epistemic status конкретного эксперимента: он зависит от версии протокола, модели среды, популяции, knowledge boundary, seed и бюджета эксперимента.

2. Experimental Contract

Каждый запуск должен иметь воспроизводимый контракт.

SimulationContract = { SimulationID, ProtocolVersion, SimulatorVersion, TargetInvariants, Scope, Horizon, EnvironmentModel, AgentPopulationModel, ObjectiveSet, RandomnessPolicy, SeedPolicy, ObservationPolicy, StopConditions, SimulationBudget, KnownBlindSpots }

Seed сам по себе не является достаточным provenance. Полная воспроизводимость требует как минимум версии протокола и симулятора, контракта эксперимента, seed, параметров среды и модели популяции.

3. Agent Model

ADVERSARIAL

Adversarial

Ищет пути к нарушению заданного инварианта в пределах доступного знания.

COOPERATIVE

Cooperative

Использует протокол по назначению и создаёт контрольную траекторию.

EXPLORATORY

Exploratory

Исследует пространство состояний без единственной цели атаки.

BOUNDARY

Boundary

Работает около границ scope, policy и допустимых переходов.

NULL

Null

Контрольная популяция без активного adversarial objective.

Популяция должна сохранять разнообразие стратегий. AAS не должен сводиться к поиску одного «идеального атакующего».

Agent = { IdentityRoot, Model, Policy, Objective, KnowledgeBoundary, ActionSpace, MemoryModel, AdaptationModel, History }

No Omniscient Agent: агент не получает автоматически доступ к скрытым состояниям, будущему, приватным evidence или внутренним данным checker.

4. Coalition и Emergent Behaviour

Атака может возникнуть не от одного агента, а из композиции допустимых локальных действий.

∀ actionᵢ: Allowed(actionᵢ) Composition(actions₁ ... actionsₙ) → Violation

Поэтому AAS поддерживает коалиции с ограниченной моделью коммуникации, формирования и распада. Коалиция не получает protocol authority.

5. Observation Layer

Observation Layer фиксирует, но не интерпретирует происходящее.

Trace = { SimulationID, ProtocolVersion, AgentPopulation, TimeRange, Actions, StateTransitions, InvariantSnapshots, ResidualMap, DissentMap, Coverage }

Интерпретация трассы относится к Evidence Extractor и Constitutional Check.

6. Evidence Coverage

Наличие evidence и его покрытие являются разными свойствами.

Coverage = { Scope, TemporalRange, StateCoverage, EventCoverage, EvidenceTypes, BlindSpots } Coverage ≠ Confidence

Большое количество запусков не означает большое покрытие. Поэтому отсутствие найденного counterexample не превращается автоматически в PASS.

Правило: отсутствие контрпримера в конечном пространстве симуляций является evidence о проведённом эксперименте, а не доказательством отсутствия нарушения.

7. Counterexample

Counterexample = { SimulationID, Trace, Trigger, ViolatedInvariant, MinimalPrefix, ReproductionData, EvidenceRoot, Scope, Limitations }

MinimalPrefix является минимальной известной последовательностью событий, достаточной для воспроизведения найденного поведения. Воспроизводимый counterexample должен становиться regression test.

8. I-5: No Total Metric

Основная новая атака на I-5 — неявное глобальное ранжирование без единого числового score.

Level 1: Explicit Global Metric Level 2: Distributed Metric Level 3: Emergent Functional Ordering

Функциональное субъектное упорядочивание существует, если совокупность локальных policy-решений фактически создаёт устойчивое отношение между субъектами, влияющее на доступ, authority, права, возможности или распределение ресурсов.

FunctionalSubjectOrdering(P) requires explicit observation of system behaviour Local Comparisons may exist. Universal, context-independent and persistent Subject Ordering is constitutionally constrained.

AAS исследует третий уровень через коалиции, интерфейсные взаимодействия, повторяющиеся решения и feedback loops.

9. AAS и Constitutional Check

Proposal | Evidence Collection | +-- Formal Proof +-- Model Checking +-- AAS Simulation +-- Researchnet Observation +-- Counterexample | Evidence Coverage | Invariant Evaluation | Constitutional Outcome

AAS не инициирует constitutional check автоматически. Он предоставляет evidence. Инициатором проверки остаётся субъект, коллектив, checker или adversarial participant согласно standing rules.

СитуацияEpistemic result

Нарушение не найденоНе PASS само по себе.

Модель не разрешает вопросUNRESOLVED или UNDECIDABLE в зависимости от причины.

10. AAS и InvariantDistance

AAS и InvariantDistance не конкурируют.

AAS = generates traces InvariantDistance = analyses bounded change Constitutional Check = evaluates invariant preservation

AAS может обнаружить последовательность действий, которую InvariantDistance затем исследует как возможную эрозию. При этом ни одна из систем не получает права создавать глобальный score субъекта.

11. Minimum Knowledge

Для AAS вводится отдельный Knowledge Profile.

ProfileНазначение
PublicИнформация, доступная обычному участнику.
ScopedИнформация, необходимая конкретному эксперименту.
Simulation-onlyСпециальная информация sandbox, которая не должна автоматически становиться production knowledge.

Расширение знания агента ради удобства симуляции не должно автоматически считаться доказательством поведения реального участника.

12. Simulation Budget

SimulationBudget = { MaxAgents, MaxSteps, MaxBranches, MaxWallTime, MaxEvidenceSize }

Бюджет является частью evidence. Результат без информации о вычислительном и исследовательском бюджете может создавать иллюзию покрытия.

13. Control Population

Adversarial population должна по возможности сравниваться с контрольной population. Это помогает отделить поведение, вызванное стратегией атаки, от ошибки simulator или environment model.

14. Regression Loop

AAS Run | Counterexample | Minimal Prefix | Regression Test | Reference Checker | Future AAS Runs

Таким образом, AAS превращает найденные ошибки в долговременный исследовательский corpus, а не только в одноразовый отчёт.

16. Failure Modes

Simulation Bias

Модель среды не соответствует релевантному аспекту протокола.

Population Collapse

Разнообразие стратегий исчезло под давлением оптимизации.

Coverage Illusion

Много запусков исследуют один и тот же небольшой участок пространства.

Coalition Blindness

Индивидуальные агенты безопасны, но коалиция создаёт нарушение.

Emergent Blindness

Нарушение возникает без заранее заданного objective.

Objective Drift

Каталог целей постепенно смещается к удобным сценариям.

Simulator Leakage

Поведение агента использует детали simulator вместо свойств протокола.

Evidence Weaponization

Simulation evidence начинает использоваться как authority или санкция.

17. Границы AAS

  • AAS не доказывает безопасность production.
  • AAS не имеет standing в governance.
  • AAS не изменяет invariants.
  • AAS не блокирует upgrade.
  • AAS не наказывает агентов.
  • AAS не определяет моральную ценность субъекта.
  • AAS не устраняет Residual.
  • AAS не может исследовать то, что не представлено его моделью.

19. Что пока нельзя утверждать

  • Нельзя утверждать, что AAS обнаруживает все классы эрозии.
  • Нельзя утверждать, что отсутствие counterexample означает PASS.
  • Нельзя утверждать, что distributed global ranking обнаруживается в общем случае.
  • Нельзя утверждать, что agent diversity сохраняется при любой оптимизации.
  • Нельзя утверждать, что AAS не может стать vector of attack.
  • Нельзя утверждать, что AAS совместим с I-9 без дополнительных ограничений.
  • Нельзя утверждать, что AAS заменяет Researchnet или adversarial science.
