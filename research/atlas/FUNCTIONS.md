## Принцип распределённости

Функция не должна автоматически привязываться к одной анатомической области.

Atlas хранит связи:

```
function
  ↓
multiple regions
  ↓
networks
  ↓
observed behavior / task
```

## Developer Mode

Для задач программирования Atlas может использовать цепочку:

```
TASK
↓
COGNITIVE FUNCTION
↓
NEURAL SYSTEM
↓
EVIDENCE
```

Например, программирование может включать внимание, рабочую память, планирование и когнитивную гибкость.

Но наличие влияния фактора на отдельную когнитивную функцию не является автоматически доказательством изменения производительности программиста.
