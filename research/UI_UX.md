# UI / UX

## Core screen

**PERCEPTION ATLAS // HUMAN BODY IMPACT**

Left: interactive human silhouette.  
Right: evidence panel.

Mobile: silhouette first, evidence panel below.

## Interaction

- hover on desktop;
- tap on mobile;
- keyboard focus;
- explicit close/back control;
- no information hidden exclusively behind hover.

## Evidence panel

**TARGET**  
Brain / Prefrontal cortex

**FACTOR**  
Smoking

**MECHANISM**  
Vascular effects

**FUNCTION**  
Cognition

**EVIDENCE**  
HIGH / MODERATE / LIMITED / CONFLICTING / INSUFFICIENT

**CAUSALITY**  
ESTABLISHED / LIKELY / SUGGESTIVE / NOT ESTABLISHED

**WHAT IS KNOWN**  
Concise evidence-based statement.

**WHAT IS NOT KNOWN**  
Uncertainty and research gaps.

**WHAT THIS DOES NOT PROVE**  
Explicit limits on individual inference.

**SOURCES**  
Primary papers and high-quality reviews.

## Visual language

- black background;
- thin white/light lines;
- restrained cyan/white glow;
- no mandatory red danger effect;
- no gore;
- no sensational imagery;
- Matrix/neural visual language may be used as an interface motif, not as evidence.

## Modes

VISUAL / EVIDENCE / QUIET ROOM / COMPARE / LAYERS / TIMELINE / REVERSIBILITY

## Accessibility

Every visual state has a text equivalent.

Reduced-motion mode is respected.

Color is never the only carrier of evidence level.

## Navigation

Every screen provides:

**← BACK**  
**⌂ ATLAS**  
**QUIET ROOM**

The user never needs the browser Back button to understand or leave a subsection.
